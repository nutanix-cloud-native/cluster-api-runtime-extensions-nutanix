# Security policy

## Reporting a vulnerability

Report a security vulnerability privately through GitHub:

<https://github.com/nutanix-cloud-native/cluster-api-runtime-extensions-nutanix/security/advisories/new>

Include the affected version, the component, and a way to reproduce the issue.
Please give the maintainers time to investigate before discussing the report in
a public issue, pull request, or discussion.

## Supported releases

Published releases are listed on the
[releases page](https://github.com/nutanix-cloud-native/cluster-api-runtime-extensions-nutanix/releases).
The Cluster API contract for each release series is recorded in `metadata.yaml`
on that tag. Name the release you are running when you report an issue.
