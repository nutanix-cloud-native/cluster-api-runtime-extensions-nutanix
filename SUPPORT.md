# Support

## Community Plus

This project is supported under the Nutanix **Community Plus** model. It is a
community-supported project, not a product covered by Nutanix Support.

This code is developed in the open with input from the community through issues
and PRs. A Nutanix engineering team serves as the maintainer. Documentation is
available in the project repository.

Issues and enhancement requests can be submitted in the
[Issues tab of this repository](https://github.com/nutanix-cloud-native/cluster-api-runtime-extensions-nutanix/issues).
Please search for and review the existing open issues before submitting a new
issue. There is no Nutanix Support entitlement, SLA, or support case process for
this project; do not open a Nutanix Support case for it. Nutanix products that
bundle this project are supported under those products' own support terms.

## Getting help

## What to include

Name the CAREN release, the Cluster API version, the infrastructure provider,
and the Kubernetes version. Published releases are on the
[releases page](https://github.com/nutanix-cloud-native/cluster-api-runtime-extensions-nutanix/releases).

## Release lines

`metadata.yaml` records the Cluster API contract for each release series.
Several series can be published at the same time. The GitHub Latest badge is
the release GitHub marks as latest. Use the tag you deployed, and read
`metadata.yaml` on that tag for its contract.
